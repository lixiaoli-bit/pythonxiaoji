① A股 · baostock 全免费 · 免注册 · 入门首选

股票代码：sh.600000 浦发银行 前复权 adjustflag=2
# ① A股：baostock（全免费、免注册，入门首选） import baostock as bs import pandas as pd bs.login() # 免费登录（无需账号密码），不登录拿不到数据 rs = bs.query_history_k_data_plus( "sh.600000", # 股票代码：sh=上交所、sz=深交所、bj=北交所 "date,open,high,low,close,volume", # 要哪些字段 start_date='2026-08-01', # 开始日期 end_date='2026-08-07', # 结束日期 frequency="d", # d=日线，w=周线，m=月线，5/15/30/60=分钟线 adjustflag="2") # 2=前复权 rows = [] while (rs.error_code == '0') & rs.next(): rows.append(rs.get_row_data()) df = pd.DataFrame(rows, columns=rs.fields) print(df.head()) # 打印前 5 行看看 bs.logout() # 退出登录，养成好习惯
支持日线/周线/分钟线，前复权通过 adjustflag="2" 设置。
