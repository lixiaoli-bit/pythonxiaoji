Windows 安装 MySQL Server

使用官方 MySQL Installer 图形化向导，三步完成：下载、安装、配置密码。

1. 下载安装包

  • 官网下载页：dev.mysql.com/downloads/installer/
  • 推荐 mysql-installer-web-community-8.x.x.msi (在线安装包)
  • 点击 No thanks, just start my download. 开始下载

2. 运行与安装

安装类型：选择 Server only（仅服务器），一路按默认继续。
  • Path Conflicts：直接 Next
  • Installation：点 Execute，等待完成，Next
  • Product Configuration（关键）：
    • Type and Networking：端口 3306（默认），Next
    • Authentication Method：选 Use Strong Password Encryption
    • Accounts and Roles：设置 root 密码，务必牢记
    • Windows Service：勾选 Start the MySQL Server at System Startup
  • Apply Configuration：点 Execute，完成后 Finish

3. 验证安装

Win + R → cmd mysql -u root -p # 输入密码，进入命令行即成功

配置环境变量（Path）

若系统找不到 mysql 命令，需手动添加 bin 目录到 Path。

第一步：找到 MySQL 安装目录

  • 默认路径：C:\Program Files\MySQL\MySQL Server 8.0\bin
  • 复制完整路径，例如 C:\Program Files\MySQL\MySQL Server 8.0\bin

第二步：添加到系统环境变量

  • Win + R 输入 sysdm.cpl 回车
  • 高级 → 环境变量 → 系统变量 Path → 编辑
  • 新建 → 粘贴 bin 路径 → 确定

第三步：验证

# 重启 CMD，输入： mysql --version # 显示版本信息即成功

VS Code 插件：Database Client

在 VS Code 中图形化操作 MySQL，建表更直观。

  • 扩展商店搜索 Database Client（作者 cweijan）
  • 安装后，左侧活动栏出现圆柱体图标，添加 MySQL 连接
  • 填写 localhost、root、密码，连接后右键数据库 → New Table...
  • 表单界面填字段名、类型、长度、默认值，保存即建表
  • 如果没有可视化界面，先用下面命令创建

MySQL 命令 · 精讲

以下为建库、建表、增删改查核心命令，带注释。简单办法：下面👇的命令选中直接执行就ok

-- ============================================= -- 1. 创建数据库（如果不存在） -- ============================================= CREATE DATABASE IF NOT EXISTS mytest; -- ============================================= -- 2. 切换到该数据库 -- ============================================= USE mytest; -- ============================================= -- 3. 创建用户表（id、姓名、年龄、性别、邮箱） -- 性别字段名已改为 sex -- ============================================= CREATE TABLE users ( id INT AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID', name VARCHAR(50) NOT NULL COMMENT '姓名', age INT COMMENT '年龄', sex VARCHAR(10) COMMENT '性别', email VARCHAR(100) COMMENT '邮箱' ); -- ============================================= -- 4. 查看表结构 -- ============================================= DESC users; -- ============================================= -- 5. 插入测试数据（注意字段名是 sex） -- ============================================= INSERT INTO users (name, age, sex, email) VALUES ('张三', 25, '男', 'zhangsan@test.com'), ('李四', 30, '女', 'lisi@test.com'); -- ============================================= -- 6. 查询表中所有数据 -- ============================================= SELECT * FROM users; -- ============================================= -- 7. 按条件查询（示例：查所有男性） -- ============================================= SELECT * FROM users WHERE sex = '男'; -- ============================================= -- 8. 插入更多数据（sex 字段） -- ============================================= INSERT INTO users (name, age, sex, email) VALUES ('王五', 28, '男', 'wangwu@test.com'); -- ============================================= -- 9. 删除指定数据（按 id 删） -- ============================================= DELETE FROM users WHERE id = 3; -- ============================================= -- 10. 清空表数据（保留表结构，id 重置从 1 开始） -- ============================================= TRUNCATE TABLE users; -- ============================================= -- 11. 删除整张表（慎用！） -- ============================================= -- DROP TABLE IF EXISTS users; -- ============================================= -- 12. 删除整个数据库（慎用！） -- ============================================= -- DROP DATABASE IF EXISTS mytest;
命令速记：
CREATE DATABASE 建库 · USE 切换 · CREATE TABLE 建表 · DESC 看结构 · INSERT INTO 插入 · SELECT 查询 · DELETE 删除 · TRUNCATE 清空 · DROP 删除（慎用）
