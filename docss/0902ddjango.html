Django 项目 · 从零创建 2026-09-02

前置 · 环境

确保 Python 已安装，到指定目录操作。

1. 创建虚拟环境

# Windows cmd执行 创建：python3 -m venv .venv 激活：.venv\Scripts\activate # Mac / Linux python3 -m venv venv source venv/bin/activate

2. 安装 Django

pip install django # 或指定版本 pip install django==4.2.15

3. 创建项目

django-admin startproject myproject .

末尾加 . 表示当前目录，不加则多嵌套一层 myproject/。

4. 创建应用 (App)

python manage.py startapp blog

5. 注册应用

打开 myproject/settings.py，在 INSTALLED_APPS 中添加：

INSTALLED_APPS = [ 'django.contrib.admin', # ... 其他默认应用 'blog', # 添加你的应用 ]
注册作用：让 Django 知道这个 App 存在，才能执行迁移、加载模板等。

6. 启动开发服务器

python manage.py runserver

访问 http://127.0.0.1:8000 查看是否成功。

项目结构示意

myproject/ ├── manage.py ├── myproject/ │ ├── __init__.py │ ├── settings.py │ ├── urls.py │ └── wsgi.py └── blog/ ├── migrations/ ├── __init__.py ├── admin.py ├── models.py └── views.py

创建第一个页面

让你看到实际效果。

1. 编写视图 (views.py)

from django.shortcuts import render from django.http import HttpResponse def home(request): return HttpResponse("Hello, Django! 这是我的第一个页面")

2. 创建应用内路由 (blog/urls.py)

from django.urls import path from . import views app_name = 'blog' # 命名空间 urlpatterns = [ path('', views.home, name='home'), # 空字符串 -> 根路径 ]

3. 将应用路由接入项目

修改 myproject/urls.py：

from django.contrib import admin from django.urls import path, include urlpatterns = [ path('admin/', admin.site.urls), path('', include('blog.urls')), # 包含 blog 路由 ]
path('', include('blog.urls')) 表示所有请求（包括 / ）都交给 blog.urls 处理。
若写 path('blog/', include('blog.urls')) 则所有 /blog/xxx 请求转发。

4. 启动服务器查看效果

python manage.py runserver

浏览器访问 http://127.0.0.1:8000 ，应该能看到 "Hello, Django! 这是我的第一个页面"。
